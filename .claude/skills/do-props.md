# do-props

현재 작업 디렉터리에 `props.md` 파일이 존재하는지 확인하고, 존재하면 읽는다.

`props.md`는 상위 세션(루트 디렉터리)에서 하위 세션(현재 세션)으로 전달하는 문서이다. 다음 두 가지 내용이 포함될 수 있다:

## 1. 상위 세션에서 작업된 내용 리뷰

"이미 작업된 뼈대" 또는 유사한 섹션이 있다면:
- 나열된 파일들을 실제로 읽어서 변경 내용이 props에 기술된 의도와 일치하는지 확인한다.
- 문제가 있으면 사용자에게 보고한다. 문제가 없으면 간단히 확인 완료를 알린다.

## 2. 지시사항(TODO) 구현

"TODO" 또는 "처리 요구사항" 등의 섹션이 있다면:
- 각 항목의 의도와 내용을 파악한다.
- 구현 가능한 항목은 구현을 진행한다.
- 구현이 불가능하거나 모호한 항목은 사용자에게 확인을 요청한다.

## 3. 설계 결정사항 준수

"설계 결정사항" 또는 "의도적으로 하지 않는 것" 섹션이 있다면:
- 해당 결정을 존중하고, 구현 과정에서 이를 위반하지 않는다.

## 실행 규칙

- `props.md`가 없거나, 내용이 비어있으면 사용자에게 알리고 종료한다.
- 리뷰와 구현은 순차적으로 진행한다: 먼저 리뷰를 완료한 후 구현에 착수한다.
- 구현 시 기존 코드베이스의 패턴과 컨벤션을 따른다.
