현재까지 진행된 작업을 아래 기준으로 프로젝트 폴더의 두 파일에 반영해줘.

## progress.md
- 방금 완료된 작업을 해당 영역의 완료 목록의 최하단으로 이동하고, 완료 날짜를 `[x] (YYYY-MM-DD #N) 작업내용` 형식으로 명시
  - N은 같은 날짜 내 작업 순번(0부터 시작). 기존 항목 중 오늘 날짜의 최대 N을 찾아 +1로 결정. 오늘 항목이 없으면 0
  - N은 날짜가 바뀌면 0부터 다시 시작
  - 삭제 우선순위: 날짜 오름차순 → 같은 날이면 N 오름차순
- 완료 항목이 전체 합산 10개를 초과하면 오래된 것부터 삭제
- 각 항목은 "무엇을 왜 바꿨는지"를 3문장 이하로 남긴다.
- 진행 중이거나 새로 파악된 TODO를 우선순위에 맞게 추가/수정
- 알려진 버그나 메모 사항이 있으면 반영
- 날짜를 오늘 날짜로 업데이트

## CLAUDE.md
- 아키텍처나 파일 구조에 변화가 생긴 경우, 변경된 컴포넌트의 해당 CLAUDE.md만 수정
- 루트 CLAUDE.md는 서브 CLAUDE.md 참조 구조 자체가 바뀐 경우에만 수정
- 변화가 없으면 건드리지 않음

## 커밋 메시지 추천
- 위 반영 작업을 마친 뒤, 이번에 완료된 작업 내용을 바탕으로 커밋 메시지를 추천
- 컨벤션 스타일은 작업 내용에 맞게 자유롭게 판단 (변경 규모나 프로젝트 관례에 따라 Conventional Commits 형식 또는 간결한 한 줄 요약 중 적합한 쪽 선택)
- 여러 작업이 섞여 있다면 대표 작업 하나를 헤더로 삼고, 나머지는 커밋 메시지 본문에 bullet로 정리
- 실제 커밋은 수행하지 않고, 메시지만 제안
