# Claude Code Prompt Logs

이 폴더에는 프로젝트 개발 과정에서 Claude Code를 활용하며 작성한 프롬프트와, 해당 프롬프트 및 AI 활용 방식에 대한 피드백을 정리했습니다.

AI에게 구현 전체를 위임하기보다 코드 분석, 설계 검토, 문제 탐색, 리팩터링 후보 제안 등의 보조 도구로 활용했으며, 최종적인 구조 선택과 코드 반영 여부는 실제 구현 상태와 프로젝트 요구사항을 기준으로 직접 판단했습니다.

프롬프트 기록을 공개하는 목적은 단순히 AI 도구를 사용했다는 사실을 보여주기보다, 개발 과정에서 AI에게 어떤 정보를 제공하고 어떤 방식으로 결과를 검증·선별했는지를 함께 보여주기 위함입니다.
